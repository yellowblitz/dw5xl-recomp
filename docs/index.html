Development roadmap

01 / VERIFY

Japanese disc analysis

Verified SLPM_661.01 ELF and three overlay headers. Full-disc module verification remains.

02 / RECOMPILE

Region-specific machine code

Build new Ghidra function maps, PS2Recomp profiles and VU translators for the Japanese executable.

03 / PLAYTEST

Native Windows and Linux

Adapt the runtime and installer, then validate Japanese menus, combat, audio, save games and graphics.

Current reality: The Japanese executable and three overlay headers have been fingerprinted. This remains a development scaffold, not a playable Japanese port. The upstream playable beta supports the PAL version only. An original legally obtained Japanese disc will be required for development and for any user-side code compilation.
